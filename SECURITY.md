# Security policy

This plugin carries sign-in links and SMTP credentials, so security reports are welcome and handled first.

Please report a vulnerability **privately** through GitHub: **Security → Report a vulnerability** on
https://github.com/apsulis/emdash-light-smtp. Do not open a public issue. We aim to acknowledge reports within
three working days and to publish a fix, with a GitHub security advisory, as soon as it is ready.

Supported versions: the latest published version.
